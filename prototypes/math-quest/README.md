Math Quest prototype

This folder contains the interactive Math Quest prototype.

Files:
- index.html — landing page for the prototype folder
- math-quest-prototype-chat-toggle-anim-soundfile-v2.html — the prototype page

Add any required assets to this folder so the prototype works locally.

Note:
- The interactive prototype page is included here: `math-quest-prototype-chat-toggle-anim-soundfile-v2.html`.
- You can open it from the Projects page (click "Math Quest") or open the file directly in your browser for local preview.
- Sound effects in this prototype are embedded as data URIs, so no extra audio files are required.
- Avoid using `file:///` links in committed HTML if you want the site to work when hosted; prefer repo-relative paths or GitHub Pages for public hosting.

If you maintain the prototype in a separate repo, consider copying updates here or adding that repo as a submodule so the Projects page can link to an in-repo file.
